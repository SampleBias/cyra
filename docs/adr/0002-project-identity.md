# ADR 0002 — Cyra project identity

Date: 2026-10-22. Status: accepted from explicit user instruction.

The project is **Cyra**, meaning **Cybernetic Cellular Intelligence**. This replaces VMSC as the product/workspace identity. Packages use `cyra-*`. The required CLI remains `vmcell`, with `vmcell.protocol.v1` and `vmcell.result.v1` schema names.

Scientific scope is unchanged: begin with an illustrative WJ-MSC profile, retain distinct causal query meanings, and withhold physiological prediction claims until independent experimental evidence supports them.
